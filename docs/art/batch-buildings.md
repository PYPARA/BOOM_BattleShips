# 批量建模任务二：建筑与野怪（交给 Codex 子代理）

目标：给 13 个建筑（岸防炮塔 `h00K` 已有模型，跳过）和 6 种野怪在 Aha 3D 工坊里各建一个 Three.js 模型，采用后拉进本仓库。流程和工具与船只那一批相同，见 [batch-modeling.md](batch-modeling.md) 的「准备」和「驱动 Aha 的两种方式」两节；这里只写不同的地方。

## 边界

- 只改这些路径：`art/concepts/`、`packages/client/public/models/buildings/`、`packages/client/public/models/creatures/`、本文件末尾的进度表。`art/manifest.json` 已经加好条目，不需要改。
- 不要动 `packages/` 下的源码（包括 `rigs.ts`）和 `docs/art/batch-modeling.md`——另一个代理正在改客户端，接入游戏由它来做。
- 不要 git commit、不要切分支。`key.json` 只让脚本读取，不要打印、复制或提交。
- Aha 里已有的工程（船只、炮塔等）不要删改。

## 概念图

`art/manifest.json` 里 `kind` 为 `building` 和 `creature` 的条目：

node tools/art/src/generate.ts n000 n003 h00M h012 n001 n002 n00Y n012 n011 n005 n014 n00U repair --refs

## 建筑

- 工程名 `{编号} {中文名}`，例如 `n000 主基地`；修理站没有编号，用 `repair 修理站`。名称见 [image-prompts.md](image-prompts.md) 第 4 批。
- 通用要求（替换船只那份）：

  ```
  硬性要求：1）Y 轴向上，原点在底座底面中心，正面朝 +X。2）有完整的底座，不要地面、海水和地形。3）需要随阵营变色的部件（屋顶、旗帜、徽章）统一用一个材质，material.name 和 userData.ahaId 都设为 "team"，颜色先用 #3f7fe0。4）低多边形、手绘感、比例略夸张，配色按概念图，不用贴图，用多个 MeshStandardMaterial 区分材质。5）尺寸按下表的高度，三角面不超过上限。
  ```

  | 建筑 | 高度（米） | 面数上限 |
  |---|---|---|
  | 主基地 n000 | 3.2 | 8000 |
  | 码头 n003、中立港 n005、亚历山大港 n014、潜艇工厂 n00U | 1.6 | 6000 |
  | 炮塔 h00M、能量之塔 h012 | 2.5 / 2.9 | 4000 |
  | 其余商店和修理站 | 1.3 | 3000 |

- 拉取：`pnpm --filter @boom/art pull-aha "<编号> <中文名>" <编号> --kind buildings`

## 野怪

- 工程名 `{编号} {中文名}`，名称见 image-prompts.md 第 5 批。
- 通用要求：

  ```
  硬性要求：1）头朝 +X，Y 轴向上，原点在身体底部中心；身体大约一半在水下，吃水线写进 parameters 的 waterline（离底部的米数）并在 parameterDefinitions 里声明。2）不要水面和底座。3）低多边形、手绘感，配色按概念图，不用贴图，用多个 MeshStandardMaterial。4）长度和面数按下表。
  ```

  | 野怪 | 身长（米） | 面数上限 |
  |---|---|---|
  | 海怪 n00L、龙龟 ntrd、金龙王 nbzd | 3.0 | 8000 |
  | 多头蛇妖女王 n016 | 2.4 | 6000 |
  | 虎鲸 n01E、海元素 nsel | 1.8 | 4000 |

- 拉取：`pnpm --filter @boom/art pull-aha "<编号> <中文名>" <编号> --kind creatures`

## 检查和完成标准

每个模型：轮廓认得出是什么、朝向对、有 `team` 材质（建筑）或 `waterline`（野怪）、面数不超。最多改 3 轮。19 个模型都在对应目录下有 `.glb` 和 `.json` 即完成；做不出来的跳过并在进度表写原因。最后给一个简短总结。
