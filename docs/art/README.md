# 美术规范与风格手册

> 适用于 AI 美术流水线（生图 → Tripo 图生 3D → Blender 后处理 → 游戏）产出的所有模型。
> 游戏里现在用的是代码生成的占位模型（`packages/client/src/placeholderShip.ts`、`props.ts`），尺寸已经按本规范设定，换成正式模型时位置和比例不用再调。

## 1. 坐标、单位与朝向

| 项 | 规定 |
|---|---|
| 长度单位 | 1 个 glTF 单位 = 1 个游戏单位（沿用魔兽地图单位，地图宽 16384） |
| 向上 | +Y |
| 船头 | 指向 **+X**（游戏里船的朝向角 0 = 正东） |
| 原点 | 船体俯视的几何中心，高度在**吃水线**（y = 0 正好是海面） |
| 建筑原点 | 底面中心，y = 0 是地面 |
| 文件 | 每个模型一个 `.glb`，按编号命名，如 `ships/H008_lord.glb`、`buildings/n000_base.glb` |

Blender 导出 glTF 时会自动把 Blender 的 Z 向上转换成 Y 向上；在 Blender 里让船头朝 +X、吃水线放在 z = 0 即可。

## 2. 尺寸与面数预算

镜头是固定俯角 56°，默认距离 2400，船在屏幕上只有几十个像素，**轮廓比细节重要**。

| 尺寸档 | 船只示例 | 船长 | 船宽 | 三角面 | 贴图 |
|---|---|---|---|---|---|
| 小型 | 水手、圣战者、渔船、飞鱼、黄金美丽 | 约 120 | 约 36 | 1–2 千 | 512² |
| 中型 | 拦截者、破坏者、龟船、影子战舰 | 约 165 | 约 50 | 2–4 千 | 1024² |
| 大型 | 大天使、死神、黑色幽灵、腓尼基、月光 | 约 210 | 约 63 | 4–6 千 | 1024² |
| 巨大 | 领主、主宰者、麦哲伦、定远、黑珍珠 | 约 255 | 约 77 | 5–8 千 | 1024²（黑珍珠可用 2048²） |

船长 = 碰撞半径 × 3。碰撞半径按尺寸档取 40 / 55 / 70 / 85（见 `packages/sim/src/world.ts`）。

建筑按 `units.json` 里的 `collision` 定占地：主基地、码头约 50，炮塔约 72，商店 40–50；高度参考占位模型（炮塔 190–260，主基地约 300）。

## 3. 材质与阵营色

- 每个模型**一个材质、一张贴图**（基础色；可选一张 ORM 贴图：AO / 粗糙度 / 金属度）。
- 贴图里**不要烘焙光影和高光**，光照交给引擎。生图时就要求平光、无投影。
- **阵营色**（南方蓝 / 北方红）不画进贴图。船上需要变色的部分（帆、旗、船舷彩带）单独拆成名为 `team` 的材质或网格，引擎运行时上色。
- 帆、旗、绳索由引擎程序化生成并挂到挂点上，模型里**只做船体和上层建筑**。这样可以避开图生 3D 不擅长的细长结构，帆也能随风动。

## 4. 挂点

在 Blender 里用空物体（Empty）标出，导出后是 glTF 节点，名字固定：

| 节点名 | 用途 |
|---|---|
| `mast_1` … `mast_n` | 桅杆底座位置（引擎在这里生成桅杆、帆和旗） |
| `muzzle_1` … `muzzle_6` | 炮口，对应 6 个物品栏；开火特效从离目标最近的炮口发出 |
| `wake` | 船尾，尾迹和水花从这里出 |
| `fx_center` | 技能特效（冰冻、护盾等）的中心 |
| `hit` | 被击中特效的位置，可选 |

## 5. 风格手册（初稿）

- **风格**：风格化低多边形 + 手绘质感贴图，比例略夸张（上层建筑偏大、船身偏短胖），俯视时一眼能分辨船型。
- **色调**：木色偏暖棕，金属件偏旧铜和铁灰，避免高饱和；阵营色只出现在 `team` 部分。
- **每类船的识别特征**：同一档尺寸的船要靠轮廓区分，例如龟船的龟甲顶、月光的新月形船身、伊谢尔伦的圆盘要塞、黑色幽灵的细长高速船身。
- **细节下限**：小于 4 个游戏单位的细节在默认镜头下看不见，不要做。

### 生图提示词模板

每次出图都带同一组风格参考图（先挑 3–5 张满意的图固定下来），提示词用英文效果更稳定：

```
Stylized low-poly fantasy warship, {ship description}, hand-painted texture,
side view and 3/4 top view, plain light grey background, flat even lighting,
no shadows, no water, no sails or ropes, game asset concept, chunky proportions
```

`{ship description}` 用中文资料翻译，例如领主："a massive dark iron battleship with a fortified central keep and heavy bow ram"。

**版权**：提示词里不要出现 Warcraft、Blizzard 或具体作品名；黄金美丽、黑珍珠、飞行的荷兰人公开发布前要重新设计外形并改名（见 `docs/PLAN.md`）。

## 6. 流水线试点（待开始）

试点用三艘外形差别大的船：**水手**（小型）、**龟船**（中型、特殊轮廓）、**领主**（巨大）。要跑通：

1. 生图：对比 2–3 个生图模型，定下用哪家；
2. Tripo 图生 3D：每艘出 3–4 个候选，挑一个；
3. Blender 无头后处理：朝向、比例、原点、减面到预算、标挂点、导出 GLB；
4. glTF-Transform 压缩（Meshopt + KTX2）；
5. 换进游戏，和占位模型对比大小与观感。

需要先准备：生图服务和 Tripo 的账号与 API Key（放进本地环境变量，不进仓库），并确认它们的商用条款。
