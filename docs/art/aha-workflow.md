# 用 Aha 3D 工坊建模

正式模型由 Aha 的 3D 工坊生成（Three.js 模式，会话模型 gpt6.1sol），再拉进本仓库。比在这里手写建模代码快，也省 token。

## 流程

1. **Aha → 3D 工坊 → 新建工程**，建模方式选 **Three.js**，工程名用 `{编号} {中文名}`，例如 `H000 水手`。
2. **开始建模对话**，模型选 **gpt6.1sol**。附上概念图 `art/concepts/{编号}_{英文名}_34.png` 和 `_side.png`，粘贴下面对应船的说明。
3. 在工坊里看效果，不满意就继续用自然语言让它改；满意后点 **采用此版本**。
4. 在本仓库拉取模型：

   ```bash
   pnpm --filter @boom/art pull-aha "H000 水手" H000
   ```

   脚本按工程名（或工程 ID）找到工程，取已采用的版本（没有采用时取当前预览版本并给出提示），把 `model.glb` 复制到 `packages/client/public/models/ships/H000.glb`，同时写一份 `H000.json` 记录来源版本和吃水线。
5. 刷新游戏或 `/viewer.html` 即可看到新模型；没有 GLB 的船继续用代码生成的模型。

## 通用要求（每艘船都附上）

```
硬性要求：
1. 船头朝 +X 方向，Y 轴向上，原点在船底中心（工坊默认即可）。
2. 只做船体和甲板上层建筑，不要桅杆、帆、绳索和旗杆，游戏引擎会另外生成。
3. 需要随阵营变色的部件（船身色带、盾徽、小旗）统一使用一个材质，material.name 和 userData.ahaId 都设为 "team"，颜色先用 #3f7fe0。
4. 风格：低多边形、手绘感、比例略夸张，配色按概念图；不用贴图，用多个 MeshStandardMaterial 区分颜色和材质。
5. 在 parameters 里加一个 waterline 参数：吃水线离船底的高度（米），并在 parameterDefinitions 里声明。游戏会把这条线对齐到海面。
6. 尺寸：船长 {长度} 米，三角面不超过 {面数}。游戏会再统一缩放。
```
