# 批量建模任务（交给 Codex 子代理）

目标：给其余 28 艘玩家船和 4 个 NPC 舰队模型，在 Aha 3D 工坊里各建一个 Three.js 模型，采用后拉进本仓库。流程与 [aha-workflow.md](aha-workflow.md) 相同，这里写的是批量执行时的细节和边界。

## 边界

- 只改这些路径：`art/concepts/`、`packages/client/public/models/ships/`、`packages/client/src/models/rigs.ts`、本文件末尾的进度表。不要动 `packages/sim`、`packages/ai`、`packages/client/src` 里其它文件——另一个代理同时在改它们。
- 不要 git commit、不要切分支。
- `key.json` 里是密钥：可以让脚本读取，不要打印、复制或提交它的内容。
- Aha 里已有的工程（炮塔、H000、H016、H008 等）不要删改。

## 准备

1. Aha 要带调试端口运行：`curl -s http://127.0.0.1:9333/json/version` 有返回即可。没有就退出 Aha 后执行 `open -a Aha --args --remote-debugging-port=9333 --remote-allow-origins=http://127.0.0.1:9333`。
2. 概念图：`art/manifest.json` 已有全部条目。缺图的船执行
   `node tools/art/src/generate.ts <编号...> --refs`
   生成 `art/concepts/<编号>_<英文名>_34.png`、`_side.png` 和 `preview/*.jpg`。一次可以传多个编号；接口偶尔超时，失败的重跑即可。先看一眼预览图，明显不对（有桅杆帆、不是船、视角错）就重生成那一张。

## 每艘船

1. 新建工程并发出第一条说明（脚本打印工程的 hash，形如 `#/model3d/<工程 ID>`）：

   ```bash
   tools/art/src/aha-new-model.sh "<编号> <中文名>" <面数上限> \
     art/concepts/preview/<编号>_<英文名>_34.jpg art/concepts/preview/<编号>_<英文名>_side.jpg \
     "<说明>"
   ```

   说明 = 一句话描述这艘船（按概念图和 image-prompts.md 的描述，写清船体、上层建筑、武器、哪些部件用 team 材质、吃水线大约在船底以上百分之几）+ `船长 <米> 米，三角面不超过 <面数>。` + aha-workflow.md 里的「通用要求」。

   | 尺寸 | 船长（米） | 面数上限 |
   |---|---|---|
   | 小型 / h00I | 1.2 / 1.0 | 2000 |
   | 中型 / h00B | 1.65 / 1.5 | 4000 |
   | 大型 / h00H | 2.1 / 2.0 | 6000 |
   | 巨大 / h018 | 2.55 / 3.0 | 8000 |

   NPC 舰队模型（h00I/h00B/h00H/h018）的 team 材质要占比大一些，因为三个阵营靠它区分。

2. 等生成完成：`python3 tools/art/src/aha-watch.py <工程 ID>=1`（生成中界面上有「停止生成」按钮）。可以同时开 2 个工程并行，不要超过 2 个。
3. 检查：看 `~/Documents/Aha/Models3D/<工程 ID>/versions/<版本 ID>/thumbnail.png`，和概念图比。必须满足：船头朝 +X、没有桅杆和帆、有 `team` 材质、`waterline` 参数存在、轮廓能认出是哪艘船。不满足就在同一个对话里用中文具体说哪里改（`node tools/art/src/aha-cdp.mjs` 的 `eval`/`type`/`click`，或直接用 computer use 在 Aha 窗口里输入），最多改 3 轮。
4. 满意后在 Aha 里点「采用此版本」，然后拉取：

   ```bash
   pnpm --filter @boom/art pull-aha "<编号> <中文名>" <编号>
   ```

5. 在 `packages/client/src/models/rigs.ts` 的 `shipRigs` 里按 image-prompts.md 的「帆的样式」加桅杆：x/height/width 是船长的比例，style 取 `square`/`lateen`/`junk`，sailColor 用十六进制颜色。「无帆」的船不加条目。参照已有的 H000/H016/H008。
6. 在下面的进度表里记一行。

## 驱动 Aha 的两种方式

- **CDP（首选，快且准）**：`node tools/art/src/aha-cdp.mjs eval '<js>'`、`shot <文件>`、`click <x> <y>`、`type '<文字>'`、`key <键>`、`files '<选择器>' <文件...>`。常用元素：「新建 3D 工程」按钮、「属性」/「AI 助手」标签、`[contenteditable=true]` 输入框、`button[aria-label="发送消息"]`、`button[aria-label="停止生成"]`、「采用此版本」按钮。
- **Computer use**：CDP 不好处理的界面（弹窗、找不到的按钮）直接在 Aha 窗口里操作。

## 完成标准

32 个模型都在 `packages/client/public/models/ships/` 下有 `.glb` 和 `.json`，有帆的船在 `rigs.ts` 里有条目，`pnpm --filter @boom/client build` 通过。做不出来或反复失败的船跳过，在进度表里写原因。
